# Privacy Policy – Leonida Clips Publisher

_Last updated: November 15, 2026_

## What this application does

Leonida Clips Publisher is a private, self-operated tool that uploads short gaming video clips to YouTube and TikTok channels owned and operated by the developer. It is not offered to the public and has no external users.

## Data we access

The application uses the YouTube Data API and the TikTok Content Posting API solely to upload videos and set their title, description and hashtags on channels that belong to the developer. It accesses only the authorization tokens required for those uploads.

## Data we store

Authorization tokens are stored locally on the developer's own computer and are never transmitted to third parties. No personal data of viewers, commenters or any other users is collected, stored or processed. The application does not read comments, subscriber lists, analytics or any other channel data.

## Data sharing

No data is sold, shared or disclosed to any third party.

## Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time via the Google account security settings (myaccount.google.com/permissions) or the TikTok app settings under "Security and permissions".
